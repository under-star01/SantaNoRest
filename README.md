# SANTA_NO_REST

**Santa No Rest**는 시야와 소리 기반 감지 시스템을 활용한  
**3D 잠입 액션 프로젝트**입니다.

적의 감지를 피하며 목표를 수행하는 구조로 구성했으며,  
발각도 누적 시스템을 통해 긴장감 있는 잠입 플레이를 구현했습니다.

---

## 프로젝트 개요

- **장르** : 3D 잠입 액션
- **개발 인원** : 5인 팀 프로젝트
- **개발 환경** : Unity, C#

---

## 주요 특징

- 시야 및 소리 기반 감지
- 발각도 누적 시스템
- 목표 수행 중심 플레이
- 가시성 보조 시각 효과
